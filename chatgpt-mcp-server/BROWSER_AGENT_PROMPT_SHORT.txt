配置 ChatGPT MCP 连接器 - 浏览器 Agent 提示词

目标：在 ChatGPT 桌面版中创建连接器，连接到本地 MCP Gateway

前置条件：
1. Gateway 运行在 http://localhost:3000/sse
2. ngrok 已启动，获取 HTTPS URL
3. ChatGPT 桌面版已打开

执行步骤：
1. 打开设置：点击左下角 ⚙️ 或按 Cmd+, (Mac) / Ctrl+, (Win)
2. 进入 Apps & Connectors：点击 "Apps & Connectors" 或 "应用与连接器"
3. 启用开发者模式：滚动到底部 → Advanced settings → 启用 Developer mode 开关
4. 创建连接器：点击 "Create" 按钮
5. 填写表单：
   - Connector name: HawaiiHub MCP Gateway
   - Description: 本地 MCP 工具网关，提供 Firecrawl、GitHub、文件系统等工具
   - Connector URL: https://your-ngrok-url.ngrok-free.app/sse
     ⚠️ 重要：URL 必须以 /sse 结尾（不是 /mcp）
6. 提交：点击 "Create" 按钮
7. 验证：成功应显示 34 个工具列表

关键信息：
- URL 格式：https://xxx.ngrok-free.app/sse（必须 /sse）
- 获取 ngrok URL：从运行 ngrok http 3000 的终端复制 Forwarding 行的 HTTPS URL
- 成功标志：显示工具列表（github: 26, firecrawl: 6, time: 2）

故障排查：
- 找不到 Developer mode：滚动到页面最底部，查找 Advanced 部分
- 连接失败：检查 Gateway 和 ngrok 是否运行，验证 URL 格式
- URL 错误：确保使用 /sse 端点，不是 /mcp
