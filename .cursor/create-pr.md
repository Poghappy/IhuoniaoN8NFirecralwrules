# 创建 Pull Request

帮我创建一个 Pull Request，包含以下内容：

## PR 标题

生成一个清晰、描述性的 PR 标题，格式：`[类型] 简短描述`

类型包括：
- `feat`: 新功能
- `fix`: Bug 修复
- `docs`: 文档更新
- `style`: 代码格式调整
- `refactor`: 代码重构
- `perf`: 性能优化
- `test`: 测试相关
- `chore`: 构建/工具相关

## PR 描述

### 📋 变更摘要

简要说明本次 PR 的主要变更内容

### 🎯 变更目的

说明为什么要做这些变更，解决了什么问题

### 🔧 主要变更

列出主要的代码变更：
- 文件1：变更内容
- 文件2：变更内容
- ...

### 🧪 测试情况

说明如何测试这些变更：
- [ ] 单元测试已通过
- [ ] 集成测试已通过
- [ ] 手动测试已完成
- [ ] 性能测试（如需要）

### 📸 截图/演示

如果是 UI 变更，提供截图或 GIF 演示

### ⚠️ 注意事项

列出需要特别注意的地方：
- 是否需要数据库迁移？
- 是否需要更新配置？
- 是否有破坏性变更？
- 是否需要更新文档？

### 🔗 相关链接

- Issue: #xxx
- 设计文档: [链接]
- 相关 PR: #xxx

## 检查清单

在创建 PR 前，确认以下事项：

- [ ] 代码已通过 linter 检查
- [ ] 所有测试已通过
- [ ] 代码已经过自我审查
- [ ] 添加了必要的注释
- [ ] 更新了相关文档
- [ ] 没有遗留的 console.log 或调试代码
- [ ] 提交信息清晰明确
