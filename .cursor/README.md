# Cursor 命令目录

本目录包含可在 Cursor 聊天中通过 `/` 前缀触发的自定义命令。

## 📋 可用命令

### 代码质量

- `/code-review` - 全面的代码审查
- `/refactor-code` - 代码重构建议

### 开发流程

- `/create-pr` - 创建 Pull Request
- `/run-tests` - 运行测试并修复问题
- `/debug-issue` - 调试问题

### 文档生成

- `/generate-docs` - 生成代码文档

### 新闻采集（项目特定）

- `/collect-news` - 执行新闻采集任务
- `/analyze-news` - 分析新闻数据
- `/export-news` - 导出新闻数据

## 🚀 使用方法

### 1. 在聊天中使用

在 Cursor 的聊天输入框中输入 `/`，会自动显示可用命令列表。

### 2. 选择命令

点击或输入命令名称，命令内容会自动加载到聊天中。

### 3. 提供上下文

根据命令的要求，选择相关文件或提供额外信息。

### 4. 执行命令

AI 会根据命令的指示执行相应的任务。

## 📝 命令格式

每个命令文件都是一个 Markdown 文件，包含：

- **命令标题**：清晰描述命令的功能
- **执行步骤**：详细的执行指南
- **输出格式**：期望的输出格式
- **示例**：使用示例和代码模板

## 🎯 最佳实践

### 命令设计

- **专注性**：每个命令专注于一个特定任务
- **清晰性**：指令清晰、易于理解
- **可复用**：适用于多种场景
- **标准化**：统一的输出格式

### 使用技巧

1. **选择合适的命令**：根据任务选择最合适的命令
2. **提供足够的上下文**：使用 `@file` 引用相关文件
3. **明确具体需求**：在命令基础上补充具体要求
4. **迭代优化**：根据结果调整和优化

## 📚 命令详解

### /code-review

**用途**：对代码进行全面审查

**适用场景**：
- 提交 PR 前的自我审查
- 代码质量检查
- 发现潜在问题

**使用示例**：
```
/code-review @src/news_collector.py
```

### /refactor-code

**用途**：重构代码，提升质量

**适用场景**：
- 代码过于复杂
- 存在重复代码
- 需要改善结构

**使用示例**：
```
/refactor-code @src/crawler.py
请重点优化数据处理部分
```

### /create-pr

**用途**：生成 PR 描述和检查清单

**适用场景**：
- 创建新的 Pull Request
- 需要规范的 PR 描述

**使用示例**：
```
/create-pr
本次修改添加了新闻去重功能
```

### /run-tests

**用途**：运行测试并修复问题

**适用场景**：
- 运行单元测试
- 修复测试失败
- 提升测试覆盖率

**使用示例**：
```
/run-tests
请运行 tests/ 目录下的所有测试
```

### /debug-issue

**用途**：调试和解决问题

**适用场景**：
- 遇到错误或 bug
- 功能不符合预期
- 性能问题

**使用示例**：
```
/debug-issue
新闻采集时出现超时错误
```

### /generate-docs

**用途**：生成代码文档

**适用场景**：
- 为函数添加文档字符串
- 生成 API 文档
- 创建使用指南

**使用示例**：
```
/generate-docs @src/models.py
请为所有类和函数生成文档
```

### /collect-news

**用途**：执行新闻采集任务

**适用场景**：
- 采集特定主题的新闻
- 批量采集新闻
- 测试采集功能

**使用示例**：
```
/collect-news
采集关于"人工智能"的最新新闻，限制 10 条
```

### /analyze-news

**用途**：分析新闻数据

**适用场景**：
- 分析新闻趋势
- 统计新闻数据
- 生成分析报告

**使用示例**：
```
/analyze-news
分析最近一周的新闻数据，生成统计报告
```

### /export-news

**用途**：导出新闻数据

**适用场景**：
- 导出为不同格式
- 数据备份
- 数据迁移

**使用示例**：
```
/export-news
导出最近 100 条新闻为 CSV 格式
```

## 🔧 自定义命令

### 创建新命令

1. 在 `.cursor/commands/` 目录创建新的 `.md` 文件
2. 使用描述性的文件名（如 `deploy-production.md`）
3. 编写命令内容（使用 Markdown 格式）
4. 重启 Cursor 或重新加载窗口

### 命令模板

```markdown
# 命令标题

命令的简短描述

## 执行步骤

### 1. 步骤一

详细说明

### 2. 步骤二

详细说明

## 输出格式

期望的输出格式

## 示例

使用示例
```
