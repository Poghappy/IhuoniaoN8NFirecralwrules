# 调试问题

帮我调试当前遇到的问题。

## 问题描述

请详细描述问题：
- 问题现象是什么？
- 在什么情况下出现？
- 预期行为是什么？
- 实际行为是什么？

## 调试步骤

### 1. 收集信息

- 查看错误日志
- 检查堆栈跟踪
- 查看相关代码
- 检查配置文件
- 查看环境变量

### 2. 重现问题

- 确定重现步骤
- 准备测试数据
- 隔离问题范围
- 创建最小可重现示例

### 3. 分析原因

- 分析错误信息
- 检查代码逻辑
- 验证假设
- 使用调试工具

### 4. 提出解决方案

- 列出可能的解决方案
- 评估每个方案的优缺点
- 选择最佳方案
- 实施修复

### 5. 验证修复

- 测试修复是否有效
- 确保没有引入新问题
- 添加测试用例防止回归
- 更新文档

## 常见问题类型

### 语法错误

- 检查拼写错误
- 检查括号匹配
- 检查缩进
- 检查导入语句

### 逻辑错误

- 使用 print/console.log 调试
- 使用断点调试
- 检查条件判断
- 检查循环逻辑

### 运行时错误

- 检查空值/未定义
- 检查类型错误
- 检查数组越界
- 检查资源访问

### 性能问题

- 使用性能分析工具
- 检查数据库查询
- 检查循环效率
- 检查内存使用

### 配置问题

- 检查环境变量
- 检查配置文件
- 检查依赖版本
- 检查权限设置

## 输出格式

### 🔍 问题分析

详细分析问题的根本原因

### 💡 解决方案

提供具体的解决方案和代码示例

### 🧪 验证步骤

说明如何验证问题已解决

### 📝 预防措施

建议如何防止类似问题再次发生

### 📚 相关资源

提供相关文档、文章或工具链接
