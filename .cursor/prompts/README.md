image.pngw# Cursor 提示词模板目录

本目录存放常用的 AI 提示词模板，帮助团队成员快速使用标准化的提示词。

## 📋 使用方法

1. 在 Cursor 中打开此目录的文件
2. 复制需要的提示词模板
3. 根据实际情况修改参数
4. 粘贴到 Cursor 的对话框中

## 📁 模板分类

### 代码开发类

- `code-review.md` - 代码审查提示词
- `refactor.md` - 代码重构提示词
- `debug.md` - 调试问题提示词
- `test-generation.md` - 生成测试用例提示词

### 文档编写类

- `api-doc.md` - API 文档生成提示词
- `readme.md` - README 文档生成提示词
- `changelog.md` - 变更日志生成提示词

### 架构设计类

- `architecture.md` - 架构设计提示词
- `database-design.md` - 数据库设计提示词

## 💡 提示词编写建议

1. **明确目标**: 清楚说明你想要 AI 做什么
2. **提供上下文**: 给出必要的背景信息
3. **指定格式**: 明确输出格式要求
4. **给出示例**: 提供期望的输出示例
5. **设置约束**: 说明不应该做什么

## 🎯 示例模板

### 代码审查模板

```markdown
请审查以下代码，重点关注：
1. 代码质量和可读性
2. 潜在的 bug 和安全问题
3. 性能优化建议
4. 是否符合项目编码规范

代码：
[粘贴代码]

请按照以下格式输出：
- 问题描述
- 严重程度（高/中/低）
- 修改建议
- 改进后的代码示例
```

### API 文档生成模板

```markdown
请为以下函数生成 API 文档，包括：
1. 功能描述
2. 参数说明（类型、必填/可选、默认值）
3. 返回值说明
4. 使用示例
5. 可能的异常情况

函数：
[粘贴函数代码]

文档格式：使用 Markdown，符合项目文档规范
```

## 📝 贡献指南

如果你创建了有用的提示词模板：

1. 在本目录创建新的 `.md` 文件
2. 使用清晰的文件名（例如：`功能-用途.md`）
3. 在文件中说明使用场景和注意事项
4. 更新本 README 的模板列表

## ⚠️ 注意事项

- 不要在提示词中包含敏感信息（密码、密钥等）
- 提示词应该通用，避免硬编码具体值
- 定期更新和优化提示词模板
- 删除过时或不再使用的模板
