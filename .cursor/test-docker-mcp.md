# Docker Hub MCP Server 测试

请执行以下测试步骤：

## 1. 配置检查

- 验证 `.cursor/mcp.json` 配置是否正确
- 检查 Docker Hub PAT 是否已设置
- 确认环境变量配置
- 验证 MCP Server 路径

## 2. 功能测试

### 搜索功能

- 测试基本搜索：`docker search nginx`
- 测试官方镜像搜索
- 测试带过滤条件的搜索
- 测试搜索结果分页

### 仓库管理

- 列出所有仓库
- 创建测试仓库
- 更新仓库信息
- 删除测试仓库

### 标签操作

- 列出镜像标签
- 获取特定标签信息
- 查看标签详情

## 3. 错误处理

- 测试无效令牌的处理
- 测试网络错误的处理
- 测试 API 限流的处理
- 测试无效参数的处理

## 4. 性能测试

- 检查缓存是否生效
- 测试并发请求处理
- 验证响应时间
- 检查内存使用

## 5. 安全测试

- 验证令牌不会泄露到日志
- 检查 HTTPS 连接
- 测试权限控制

请报告所有测试结果，包括成功和失败的情况，并提供详细的错误信息。
