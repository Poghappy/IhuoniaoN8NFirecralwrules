## 数据流程

### 采集任务创建流程

1. 插件管理 → 信息资讯采集插件
2. 采集节点管理 → 添加任务
3. 基础配置 → 内容提取规则 → 保存
4. 返回节点列表 → 执行采集
5. 配置采集参数 → 开始采集

### 关键URL路径

- 登录: `/admin/login.php`
- 主页: `/admin/index.php`
- 插件管理: `/admin/siteConfig/plugins.php`
- 添加节点: `./insertNode.php`
- 采集执行: `./index.php?getView={id}&type={type}`
