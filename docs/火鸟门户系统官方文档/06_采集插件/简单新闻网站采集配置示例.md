## 🛠️ 配置步骤详解

### 步骤1：分析目标网站

1. **打开目标文章页面**
2. **右键点击标题 → 检查元素**
3. **查看HTML结构，记录标记**
4. **重复检查2-3篇文章确认一致性**

### 步骤2：设置采集节点

1. **登录后台** → 插件管理 → 火鸟采集
2. **点击"添加任务"**
3. **填写节点名称和URL规则**
4. **选择"采集单页面"**

### 步骤3：配置HTML标记

```
按照分析结果填写：
- 标题开始/结束标记
- 正文开始/结束标记  
- 作者开始/结束标记（可选）
- 时间开始/结束标记（可选）
- 来源开始/结束标记（可选）
```

### 步骤4：测试采集

1. **点击"测试采集"**
2. **检查提取的内容是否正确**
3. **如有问题，调整HTML标记**
4. **重复测试直到满意**

### 步骤5：执行采集

```
设置采集参数:
- 采集间隔: 2-3秒
- 采集数量: 10-20篇（测试用）
- 点击"开始采集"
```

## ⚡ 快速故障排除

### 问题1：标题提取失败

```
原因: HTML标记不准确
解决: 使用更通用的标记如 <h1> 而不是具体class
```

### 问题2：正文内容不完整

```
原因: 结束标记匹配到了错误位置
解决: 检查是否有嵌套的相同标签，使用更精确的标记
```

### 问题3：采集到重复内容

```
原因: URL规则过于宽泛
解决: 缩小URL匹配范围，添加更具体的路径
```

### 问题4：网站访问被拒绝

```
原因: 访问频率过高或User-Agent被识别
解决: 增加采集间隔，修改User-Agent设置
```

## 📈 优化建议

### 提高成功率

1. **使用简单标记**: 优先使用 `<h1>`, `<article>`, `<div>` 等基础标签
2. **设置备用标记**: 为重要内容设置多个可能的标记
3. **适当间隔**: 不要设置过短的采集间隔
4. **小批量测试**: 先采集少量内容验证配置

### 内容质量控制

```
过滤设置:
- 最小内容长度: 200字符
- 排除关键词: "广告", "推广", "404"
- 必需元素: 标题和正文都必须存在
```

### 批量管理

```
建议策略:
1. 为不同类型网站创建不同节点
2. 设置不同的采集时间避免冲突
3. 定期检查采集质量
4. 及时调整失效的配置
```
