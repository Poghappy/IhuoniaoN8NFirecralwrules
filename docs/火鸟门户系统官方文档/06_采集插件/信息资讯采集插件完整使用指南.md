## 📖 插件概述

### 主要用途

信息资讯采集插件是火鸟门户系统的核心功能模块，专门为HawaiiHub平台提供自动化内容采集服务。该插件能够从互联网上的新闻网站、资讯平台自动采集内容，丰富平台的信息资源。

### 应用场景

- **本地新闻采集**: 采集夏威夷当地新闻资讯
- **华人社区资讯**: 获取华人社区相关信息
- **行业资讯**: 采集房产、教育、生活等各行业信息
- **内容补充**: 为平台提供持续的内容更新

## ⚡ 功能特性

### 🎯 核心功能

| 功能模块 | 功能描述 | 技术特点 |
|----------|----------|----------|
| **多模式采集** | 支持单页面、多页面、API接口三种采集方式 | 灵活适配不同网站结构 |
| **智能解析** | 自动提取标题、正文、来源、作者等信息 | HTML标记识别技术 |
| **批量处理** | 支持批量采集和发布 | 可设置采集数量和间隔 |
| **内容管理** | 采集后直接发布到新闻模块 | 无缝集成系统 |

### 📊 采集类型详解

#### 1. 单页面采集

```
适用场景: 采集单独的HTML页面
示例: https://example.com/news/article-123.html
特点: 适合采集特定的新闻文章
```

#### 2. 多页面采集

```
适用场景: 采集有分页规律的列表页面
示例: https://ihuoniao.cn/sz/article/yule/?page=(*)
特点: 支持通配符匹配，批量采集多页内容
```

#### 3. API接口采集

```
适用场景: 通过API接口获取数据
示例: http://temp.163.com/special/00804KVA/cmguonei03.js?callback=datacallback
特点: 直接获取结构化数据，采集效率高
```

## 📁 目录结构

### 插件文件组织

```
include/plugins/4/
├── 📄 index.php              # 插件主入口文件
├── 📄 insertNode.php         # 添加采集节点处理
```

## 📚 使用指南

### 🎯 创建采集任务

#### 步骤1: 添加采集节点

1. **进入插件界面**

   ```
   后台首页 → 插件 → 火鸟采集 → 采集节点管理
   ```

2. **点击"添加任务"**
   - 填写节点名称
   - 选择采集类型
   - 配置URL规则

#### 步骤2: 配置采集参数

**多页面采集配置示例:**

```
节点名称: 夏威夷本地新闻
针对类型: 采集多页面
列表页URL匹配规则: https://hawaiinews.com/local/?page=(*)
开始标记: <div class="news-list">
结束标记: <div class="pagination">
```

**内容提取规则配置:**

```
标题开始: <h1 class="article-title">
标题结束: </h1>
正文开始: <div class="article-content">
正文结束: </div>
来源开始: <span class="source">
来源结束: </span>
作者开始: <span class="author">
作者结束: </span>
```

### 🔄 执行采集任务

#### 采集参数设置

| 参数名称 | 推荐值 | 说明 |
|----------|--------|------|
| **每页采集条数** | 10-20条 | 避免对目标网站造成压力 |
| **间隔时间** | 1-3秒 | 模拟人工访问频率 |
| **采集页数** | 5-10页 | 根据需要调整 |

#### 执行流程

1. **启动采集**

   ```
   点击"采集"按钮 → 设置参数 → 开始采集
   ```

2. **监控进度**
   - 实时查看采集状态
   - 检查采集日志
   - 处理异常情况

3. **查看结果**
   - 预览采集内容
   - 检查内容质量
   - 筛选有效信息

### 📤 发布采集内容

#### 批量发布设置

```
选择城市: 火奴鲁鲁
导出分类: 本地新闻
每批导出数量: 20条
每批导出间隔: 1秒
发布状态: 待审核
```

#### 发布流程

1. **内容筛选**
   - 选择要发布的内容
   - 检查内容质量
   - 设置发布参数

2. **批量发布**
   - 点击"发布内容"按钮
   - 选择目标栏目
   - 设置发布状态

3. **后续管理**
   - 在新闻管理中查看
   - 进行内容编辑
   - 审核发布状态

## 🔍 故障排除

### 常见问题及解决方案

#### 1. 采集失败问题

**问题**: 无法访问目标网站

```
解决方案:
1. 检查网络连接
2. 验证目标URL是否正确
3. 检查防火墙设置
4. 尝试更换User-Agent
```

**问题**: 内容解析失败

```
解决方案:
1. 检查HTML标记是否正确
2. 查看目标网站是否更新了结构
3. 使用浏览器开发者工具重新分析
4. 调整正则表达式匹配规则
```

#### 2. 性能问题

**问题**: 采集速度过慢

```
优化方案:
1. 增加服务器带宽
2. 优化采集间隔时间
3. 使用多线程采集
4. 启用内容缓存
```

**问题**: 内存不足

```
解决方案:
1. 增加PHP内存限制
2. 分批处理大量数据
3. 及时清理临时文件
4. 优化数据库查询
```

#### 3. 数据质量问题

**问题**: 采集内容不完整

```
检查项目:
1. HTML标记设置是否准确
2. 目标网站是否使用Ajax加载
3. 是否存在反爬虫机制
4. 内容是否需要登录访问
```
