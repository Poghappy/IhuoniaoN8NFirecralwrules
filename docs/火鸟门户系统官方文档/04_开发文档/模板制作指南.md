变量 帮助文档>二次开发>模板制作>模板语法
变量
{#$ variable#}
用美元符号后跟变量名来表示，变量名与 PHP 中其它的标签一样遵循相同的规则。
示例：
{#$ cfg basehost#}, 网站域名
{#$ article title#}, 新闻标题

逻辑判断
帮助文档>二次开发>模板制作>模板语法
逻辑判断
流程控制语句，常用于需要根据特殊条件显示不同内容的情形。
格式：{# if#}/{# else#}/{# elseif#}/ {#/ if#}
示例：
{# if $ alist. group img#}
< img class=" pic" src="{#changeFileSize url="{#$ alist. group img[0]. path#}" type=" middle"#}">
{# elseif Salist. litpic#}
< img class=" pic" src="{#$ alist. litpic#}"> {#/ if#}
表示：如果此条新闻是多图则选择图集的第一张，如果是缩略图则调用缩略图

循环
帮助文档>二次开发>模板制作>模板语法
循环
循环语句，常用语内容列表，将多条内容以相同的HTML结构显示出来。
格式：{# foreach from=$ data key=k item= value#}
$data是要循环的数据
k是当前索引值
value是当前元素
示例：
$ arr = array(9=> ' Tennis',3=> ' Swimming',8=> ' Coding');
$ smarty-> assign('myArray', $ arr);
?>
用模板按键名/键值对的形式输出$myArray.
< ul>
{foreach from=$myArray key=k item=v}
< li>{$k}: {$v}
{/ foreach}
上例将输出：
< ul>
< li>9: Tennis
< li>3: Swimming
< li>8: Coding
