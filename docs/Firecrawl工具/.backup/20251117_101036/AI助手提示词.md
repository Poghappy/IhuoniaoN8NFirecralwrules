### 3. MCP工具使用提示词

#### MCP工具选择提示词
```
选择MCP工具时请按照以下优先级：

1. 任务分析：
   - 明确任务类型和功能需求
   - 评估技术约束和性能要求
   - 确定安全级别和合规要求

2. 工具评估：
   - 浏览器自动化：playwright > puppeteer > selenium-based
   - 网页抓取：firecrawl > scrapy-based > requests-based
   - 容器管理：Docker MCP > kubernetes-mcp > podman-mcp

3. 配置验证：
   - 检查工具配置状态
   - 测试连接和权限
   - 验证功能可用性

4. 故障处理：
   - 优先调用context7 MCP
   - 查阅官方最新文档
   - 按官方说明进行配置修复
```

#### MCP故障处理提示词
```
当MCP工具出现故障时，请严格按照以下流程处理：

1. 问题诊断：
   - 全面扫描系统状态
   - 记录详细错误日志
   - 分析错误根源和影响范围

2. 解决方案执行：
   - 优先使用context7 MCP进行诊断
   - 通过firecrawl查阅官方文档
   - 严格按照官方说明修复配置

3. 验证和恢复：
   - 验证问题完全解决
   - 更新系统配置记录
   - 提交完整处理报告
   - 制定预防措施

注意：禁止跳过故障或使用其他工具规避问题，必须彻底解决后方可继续任务。
```

### 1. 代码分析提示词

#### 源码分析提示词
```
进行源码分析时请遵循：

1. 分析原则：
   - 仅基于实际存在的代码文件
   - 不对未实现功能进行推测
   - 不基于文档推测实际功能
   - 找不到相关代码时明确告知

2. 分析方法：
   - 使用search_codebase工具定位相关代码
   - 使用view_files工具查看具体实现
   - 分析代码结构和依赖关系
   - 识别关键功能和接口

3. 结果输出：
   - 提供准确的代码位置引用
```
