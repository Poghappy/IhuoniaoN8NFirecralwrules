## 🔄 后续维护建议

### 1. 建立命名规范检查脚本

```bash
#!/bin/bash
# check-naming.sh
# 检查文件命名是否符合 kebab-case 规范

find . -type f -name "*.md" -o -name "*.py" -o -name "*.json" | \
  grep -v node_modules | \
  grep -v ".git" | \
  while read file; do
    basename=$(basename "$file")
    if [[ ! "$basename" =~ ^[a-z0-9]+(-[a-z0-9]+)*\.(md|py|json|mdc)$ ]]; then
      echo "❌ 不符合规范: $file"
    fi
  done
```
