
### 4. 链接管理规范

#### 相对路径优先
```markdown
✅ 正确: [系统管理](../01_系统管理/README.md)
❌ 错误: [系统管理](/绝对路径/系统管理/README.md)
```

#### 统一链接格式
```markdown
- 内部链接: [文档名称](./文档路径.md)
- 外部链接: [网站名称](https://example.com)
- 锚点链接: [章节名称](#章节名称)
```

### 5. 版本控制规范

#### Git 提交规范
```
feat: 添加新文档
docs: 更新文档内容
refactor: 重构文档结构
fix: 修复文档错误
```

#### 文档版本管理
- 重要文档保留历史版本
- 使用语义化版本号
- 记录变更日志
