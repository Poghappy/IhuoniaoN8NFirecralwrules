# 脚本工具

> **最后更新**: 2025-01-27

## 📋 目录说明

本目录包含项目维护和管理的自动化脚本。

## 📚 脚本列表

### 文档管理
- [文档整理脚本](./reorganize-docs.sh) - 自动整理和重组文档文件
- [链接更新脚本](./update-links.sh) - 更新文档中的内部链接
- [官方文件重命名脚本](./rename-official-files-v2.sh) - 规范化官方资料文件命名

### MCP 工具
- [MCP 设置脚本](./setup-mcp.sh) - 设置 Model Context Protocol
- [MCP 测试脚本](./test-mcp.sh) - 测试 MCP 配置

## 🚀 使用方法

### 文档整理
```bash
./scripts/reorganize-docs.sh
```

### MCP 设置
```bash
./scripts/setup-mcp.sh
./scripts/test-mcp.sh
```

### 链接更新
```bash
./scripts/update-links.sh
```
