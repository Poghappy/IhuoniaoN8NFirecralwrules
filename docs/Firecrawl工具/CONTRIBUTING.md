# 贡献指南

> **版本**: v1.0  
> **最后更新**: 2025-01-27

## 📋 欢迎贡献

感谢您对 Firecrawl 工具文档项目的关注！我们欢迎各种形式的贡献。

## 🎯 贡献方式

### 1. 报告问题
- 使用 GitHub Issues 报告 bug 或提出建议
- 提供详细的问题描述和复现步骤
- 包含相关的环境信息

### 2. 提交代码
- Fork 项目仓库
- 创建功能分支 (`git checkout -b feature/AmazingFeature`)
- 提交更改 (`git commit -m 'Add some AmazingFeature'`)
- 推送到分支 (`git push origin feature/AmazingFeature`)
- 创建 Pull Request

### 3. 改进文档
- 修正拼写错误
- 改进文档结构
- 添加使用示例
- 翻译文档

## 📝 代码规范

### Python 代码
- 遵循 PEP 8 代码风格
- 使用 4 个空格缩进
- 最大行长度 100 字符
- 添加类型提示
- 编写文档字符串

### Markdown 文档
- 使用 kebab-case 命名文件
- 添加元数据头部
- 使用清晰的标题层级
- 添加代码示例

## 🔍 提交规范

### 提交信息格式
```
<type>(<scope>): <subject>

<body>

<footer>
```

### 类型说明
- `feat`: 新功能
- `fix`: 修复 bug
- `docs`: 文档更新
- `style`: 代码格式调整
- `refactor`: 代码重构
- `test`: 测试相关
- `chore`: 构建/工具相关

### 示例
```
docs(guides): 添加 Docker 部署指南

- 添加 Docker 部署步骤
- 添加配置文件示例
- 更新相关链接
```

## ✅ 检查清单

提交前请确认：
- [ ] 代码通过所有测试
- [ ] 遵循代码规范
- [ ] 更新了相关文档
- [ ] 提交信息清晰明确
- [ ] 没有引入新的警告或错误
